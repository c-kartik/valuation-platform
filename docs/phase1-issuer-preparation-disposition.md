**Proposed Phase 1 acceptance contract, requiring user choice:** keep a five-year
target for each issuer, with every required input represented as source-bound
fact, approved derivation, explicit analyst/manual input, or typed unresolved
requirement. Preserve submitted precision, scope, occurrences, evidence bytes/
digests and retrieval limitations. Short/empty histories are exceptions requiring
explicit disposition, not five-year completion. Define required input families
before packaging; reported CFO availability alone never satisfies this contract.
No economic calculation is part of it. Existing pilot acceptance is narrower
and does not satisfy the five-year issuer target.

This *evidence-accounted* target is distinct from a *complete-input* target
requiring every needed historical value and perimeter to be resolved. Recommend
the former as an auditable preparation boundary, but do not silently adopt it:
user must decide whether recorded unknowns may close preparation or instead
leave those companies incomplete. Neither route proves future consumer readiness.
The five-year target remains unchanged under either choice. Full-input completion
cannot currently be promised for all 40 from retained evidence.

## Finite completion plan and required user choice

1. **Smallest next milestone: one Phase 1 preparation acceptance-contract decision**,
   documentation only. Choose complete-input versus evidence-accounted completion;
   specify required input families, five-year exception handling and treatment of
   irreducible unknowns. Record explicit scope/author/date and stopping rules.
   Do not select tax rates or lease economics, create a valuation path or silently
   reinterpret pilot closure. Stop if that choice remains undecided.
2. Once authorized, one reusable **retained-evidence source-binding ledger** across
   all 40—not 40 separate reviews—would map five target slots and required inputs
   to selected accession/annual dates, policy/source roles, precision/digests and
   unresolved evidence. Reuse existing inventories/models; no new annotation
   architecture. Accept only identity-safe joins; stop unresolved joins with a
   precise reason. Existing records/validation alone lack full occurrence detail.
   This is a proposed bounded implementation, not performed or authorized here.
3. Publish one finite exceptions backlog grouped by identity/history, conflicts,
   exact-unit/scale gaps (e.g. Visa/MCD shares), methodology/perimeter, and source
   availability. Do not promise fixes from route labels. Address only separately
   approved essential groups with evidence and explicit gates; stop at unavailable
   disclosure or exhausted scope, not repeated research. Under complete-input
   acceptance those issuers remain incomplete; under evidence-accounted acceptance
   closure records unresolved limitations, never certifies financial sufficiency.
