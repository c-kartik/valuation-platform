The 42 non-specialized histories contain **199 selected periods**, versus a
five-period target of **210**. The forty generalization-required issuers contain

XOM has no selected history (five missing target slots); GEV/SNDK each have two
selected periods (three missing each). Missing slots have no invented dates.

“Recent” means the newest three **selected ordinal positions per issuer**, not
three fabricated consecutive calendar years; “older” means positions four/five.
For every one of the fourteen contract fields, recent denominators are **121
selected / 126 target** (five missing), older **78 / 84** (six missing). Thus the
all-field inventory is **2,786 selected / 2,940 target**. Cohort-only denominators
are 115/120 recent and 74/80 older. These definitions remain explicit when history
is short or empty; ordinal coverage does not establish continuity/comparability.

[Exact reproducible coverage](preparation-coverage-results.json) separates:

- **Valued**: any non-null input in the family, including support/components.
- **Policy-prepared**: existing selected scalar value, excluding proxies/overrides.
- **Approved complete total**: exactly one existing policy-prepared scalar with
  declared COMPLETE metadata, supported scope/review, no conflict or failed
  independent scope check. This is metadata-qualified primitive coverage, **not**
  independent whole-history certification or a consumer sufficiency assessment.
- Partial/support, conflicting, no observation, required value missing, invalid
  evidence, proxy and manual override flags are separate, potentially overlapping.

Cash/investments, debt/leases, shares and cash-flow working-capital observations
have **no approved complete-family consumer contract**. Their observation counts
cannot count as complete usable inputs; no aggregation or zero is inferred.
SBC/deferred-tax reconciliation rows likewise do not approve an economic total.
Declared partial metadata is not silently upgraded because a policy value exists.

The proposed **90% recent / 80% older** targets are compared against the declared
complete-total definition, separately with selected and full target denominators.
Every field falls short on both definitions. This is a material contract-level
shortfall for user review, not an accepted limitation or financial dollar
materiality threshold. The report also compares weaker policy-value availability;
passing that comparison must not substitute for complete-field coverage. Missing
target history is not removed to improve a percentage. No target is lowered.

## Independent evidence boundary

[Fixtures](preparation-independent-fixtures.json) contain literal visible
statement cells or note/cover passages read independently of assembly, including
exact body path, artifact catalog locator, original-body SHA-256, SEC URL, selected annual
identity, column headings, units, sign, scope and share date/class. The source
receipt is retained as it exists; no original retrieval metadata is invented.
Catalog `/artifacts/i` locators index `artifacts[i]` in object collections, or
entry `i` in legacy root-list body collections; they are not raw JSON pointers
for those root-list files. Exact path, index, URL and body digest bind the citation.

statement confirmation. Display rounding is preserved and not promoted into an
