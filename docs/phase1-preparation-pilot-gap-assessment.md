## Progress versus genuine blocker resolution

**Resolved for preparation:** exact-period evidence packaging, reusable isolated
input contracts, source-role/precision distinctions and finite analyst acceptance
decisions. Alphabet's missing receipt prerequisite is satisfied by an explicit
new receipt, not recovery of original metadata. Partial NWC scenarios expose
supported exclusions/omissions rather than silently forcing whole-book coverage.

**Not resolved:** no original frozen-v1 methodology blocker, missing state or
support classification is removed. Reproducing consolidated CFO avoids requiring
complete book-NWC reconstruction *for that reported subtotal only*. It does not
repair complete operating balances, certify cash ΔNWC, recover D&A, eliminate
acquisition effects or prove operating-tax/lease/timing compatibility.

## Forty-company preparation goal: essential versus deferrable

Essential now is a **finite universe-wide disposition of existing evidence**:
which issuer has an evidence-linked preparation record, what remains unreviewed,
which exact periods/inputs are available, and which missing items actually block
a named data-preparation scope. Three pilots are examples, not evidence that the
other 37 are reviewed, nor a requirement to build identical bundles for all 40.
All seventeen frozen measures remain tracked in each issuer record.

Defer blanket history extension, fresh issuer research, exhausted Capex research,
new estimates, complete-NWC reconstruction and broad provenance architecture.
Do not make universal coverage or valuation readiness a Phase 1 requirement.
Do not call the 40-company goal complete solely because files or pipelines exist.

**Single next milestone: retained-evidence disposition matrix for all 40
GENERALIZATION_REQUIRED issuers**, documentation only, no fresh SEC review.
Acceptance criteria:

1. Exactly 40 unique CIK rows matched to the frozen validation/register; Alphabet
   covers both tickers once. Preserve the other ten universe classifications.
2. Each row links its 17-measure record and history length, records actual review
   depth, exact existing bundle periods (or none), typed material gaps/provenance
   limits and a named permissible preparation scope. Unreviewed stays explicit.
3. Categorize next action as no further work for that scope, a specific essential
   retained-evidence check, missing disclosure/analyst decision, or deferred
   coverage work. Each essential check has a concrete question and stop rule;
   do not perform it during the disposition milestone.
4. Reconcile 3 closed pilots + 37 without equivalent closure and all frozen
   counts/classifications. Rank only evidenced bounded needs, not an automatic
   37-issuer research queue; update affected records if conclusions change.
5. Validate identities, links, provenance references and diff; preserve every
   production artifact. Stop after publishing the matrix and one finite proposal
   for user review. If evidence is absent, record that gap rather than retrieve.

This is a completion plan, not authority for additional issuer work now. It makes
the remaining preparation goal measurable while keeping unsupported economic
claims and Phase 2 decisions separate.

Validation reuses frozen validation and pinned registries: exact four identities,
40-register mapping, baseline counts and acceptance consistency; local links and
`git diff --check` pass. No SEC requests, tests, corpus, calculations, policy,
source, schema or existing artifact changes.
