## Exact reported subtotal, not adjusted cash flow

The shared retained-component API inspects only the exact selected accession's
authoritative annual dates, registrant CIK/SEC entity scheme, nondimensional
context, standard US-GAAP namespace, exact USD unit and original precision.
`NetCashProvidedByUsedInOperatingActivities` is the authorized reported
consolidated root. Continuing/discontinued standard subtotals remain explicitly
restricted, non-substitutable observations; dimensions identify narrower/component
populations, and other durations remain comparative/nonannual observations.
No populations are summed, no absent component is zero, and scope is not inferred
from numerical agreement. Unequal eligible root values remain conflicting.
Equal root values with differing precision remain distinct confirming alternatives.

The exact standard root semantics and entity/annual context identify the reported
cash subtotal. This is not an independent face-placement or operating-perimeter
re-review. All occurrences, alternatives, raw signs/units/precision, original root
ordinals, original-body/receipt provenance and excluded scope/date populations
are retained. Invalid units, nil/numeric/precision or broken bindings remain
specific null requirements; no default estimate or fallback.

Reported CFO includes the filing's cash interest/tax/lease and other reported
effects. It is **not FCFF, organic/unlevered cash flow or reconstructed book
ΔNWC**. Extraction does not prove complete CFO reconciliation or validate
acquisition/FX/reclassification effects. New values stay PARTIAL/LIMITED for this
preparation assessment; future consumer sufficiency/timing is unassessed.
